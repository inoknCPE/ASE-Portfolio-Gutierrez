# Personal Learning Goals
Throughout CPELX330, I aim to develop the following knowledge and skills:
1. **Understand agentic systems.** Explain how agents observe information, select actions, and pursue goals, and compare their behavior with traditional applications.
2. **Apply the software development life cycle.** Connect requirements analysis, design, implementation, testing, deployment, and maintenance to a small AI-assisted software project.
3. **Write clear requirements.** Translate user needs into functional and nonfunctional requirements, define an agent's goals and limits, and establish measurable acceptance criteria.
4. **Practice Agile development and collaboration.** Organize work into small increments, use feedback to improve the next iteration, and use Git and GitHub to track meaningful changes and document contributions.
5. **Collaborate effectively with AI tools.** Write clear prompts, review AI-generated code and documentation, and explain the decisions behind the work I submit.
6. **Evaluate software quality.** Develop automated tests and assess whether software and agent outputs meet requirements for correctness, reliability, and security.
7. **Learn deployment and monitoring practices.** Understand how automated delivery, logging, and monitoring support the operation and maintenance of agentic applications.
8. **Apply responsible AI principles.** Identify privacy, security, fairness, and accountability risks; define human approval and intervention responsibilities; and document AI assistance and verification honestly.
